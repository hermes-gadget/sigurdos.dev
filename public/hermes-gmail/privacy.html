PRIVACY POLICY — HERMES GMAIL (READ-ONLY)

Last updated: 30 September 2026

1. What this tool is

Hermes Gmail (read-only) is a private, single-user integration used by the owner of this website to let his own AI assistant read his own Gmail account. It is not offered to the public and has exactly one user: the account owner.

2. What data is accessed

With the account owner's explicit consent, the tool accesses Gmail data through Google's Gmail API using the gmail.readonly scope: the owner's own email messages, their metadata (senders, recipients, dates, labels) and attachments. Authentication tokens are stored locally on the owner's own hardware. The tool has no ability to send, delete or modify email.

3. How data is used

Solely to provide the tool's functionality to its single user: searching, reading and summarising the owner's own email inside his private assistant. No advertising, no profiling, no analytics.

4. Storage and sharing

All processing happens on the owner's own self-hosted infrastructure. Email data and OAuth credentials are stored only there and are never sold, shared or transferred to any third party. This website uses no cookies.

5. Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is never used for advertising and is not used to train generalised AI/ML models.

6. Revoking access and deletion

The owner can revoke this tool's access at any time via the Google Account permissions page (myaccount.google.com/permissions), which immediately blocks further access. Locally stored tokens and any cached email data can be deleted at any time; the data resides on the owner's own machine.
